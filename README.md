### Универсальный AI-ассистент в Telegram на базе n8n

Разработал универсального AI-ассистента в Telegram на базе **n8n**, который автоматически анализирует пользовательские запросы и маршрутизирует их в соответствующий сценарий обработки. В качестве LLM используется **DeepSeek**, а для работы с собственной базой знаний реализован RAG-модуль на базе **Qdrant** и эмбеддингов **nomic-embed-text через Ollama**.

**Основные возможности:**

* **AI-маршрутизация запросов** — LLM определяет тип запроса пользователя и автоматически направляет его в нужный workflow: обычный вопрос, создание заметки, генерация изображения, получение расписания, поиск по векторной базе и другие сценарии.
* **RAG-поиск по собственной базе знаний** — пользователь может задавать вопросы по сохранённым данным. Запрос преобразуется в embedding, после чего выполняется семантический поиск в **Qdrant Vector Store**. В workflow используется `top-K = 3` наиболее релевантных результатов, которые передаются AI-агенту для формирования ответа.
* **Работа с заметками** — бот по команде пользователя создаёт заметки в Markdown, автоматически формирует название и сохраняет подготовленный контент для дальнейшего использования.
* **Интеграция с внешними источниками данных** — работа с **Яндекс Диском**, Google Drive и другими подключёнными сервисами для получения и сохранения информации.
* **Поиск информации в интернете** — AI-агент может использовать **Tavily** для поиска актуальной информации в интернете и формировать ответ на основе найденных данных.
* **Обработка голосовых сообщений** — голосовые сообщения из Telegram автоматически передаются на распознавание речи через **OpenAI Speech-to-Text**, после чего полученный текст обрабатывается основным AI-сценарием.
* **Генерация изображений** — поддерживается создание изображений по текстовому запросу пользователя с использованием OpenAI.
* **Работа с расписанием** — бот получает расписание из внешних источников, обрабатывает его, группирует занятия по дням, сортирует их и отправляет пользователю в удобном формате через Telegram.
* **Автоматическое создание Telegram-постов** — бот может формировать посты на основе ранее сохранённых заметок, при необходимости дополняя информацию поиском в интернете.
* **Обработка YouTube-контента** — workflow умеет получать транскрипцию видео по ссылке через внешний сервис и преобразовывать её в текст для дальнейшей обработки AI-моделями.
* **Генерация аудио** — предусмотрен отдельный сценарий, в котором AI определяет необходимость аудиоверсии, после чего генерируется аудиофайл.
* **Работа с файлами и мультимедиа** — автоматизировано получение, загрузка, отправка и удаление файлов и медиаконтента через Telegram и подключённые облачные хранилища.
* **Автоматизация Telegram-коммуникации** — бот самостоятельно отправляет, редактирует и удаляет сообщения в зависимости от сценария обработки.

### Технологический стек

**n8n, DeepSeek, OpenAI, Qdrant, Ollama, nomic-embed-text, Tavily, Telegram Bot API, Google Drive, Яндекс Диск, JavaScript.**

В результате получился единый AI-workflow, объединяющий **LLM-агентов, RAG-поиск, семантическое векторное хранилище, обработку мультимодальных данных, поиск в интернете и автоматизацию внешних сервисов** в одном Telegram-интерфейсе.
