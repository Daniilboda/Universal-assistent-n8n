# Universal-assistent-n8**Универсальный AI-ассистент в Telegram на базе n8n**

Разработал универсального Telegram-бота, который с помощью LLM анализирует запрос пользователя и автоматически определяет необходимый сценарий обработки. Бот поддерживает работу с текстовыми, голосовыми и графическими сообщениями, распознавая голосовые сообщения и анализируя изображения с извлечением текста и ключевой информации.

Основные возможности:

* создание и автоматическое сохранение заметок в формате Markdown с интеграцией с Яндекс Диском;
* поиск информации в интернете через Tavily и формирование ответов на основе найденных данных;
* генерация изображений по текстовому описанию;
* поиск информации в собственной базе знаний / векторном хранилище;
* работа с расписанием занятий из Excel/Google Drive — получение расписания на конкретный день и автоматическая отправка напоминаний;
* автоматическое формирование Telegram-постов на основе накопленных заметок с возможностью дополнительного поиска информации в интернете;
* обработка голосовых сообщений через Speech-to-Text и изображений через AI-анализ;
* поддержка контекстной памяти диалога и автоматическая маршрутизация запросов между различными AI-сценариями;
* автоматическая отправка, редактирование и закрепление сообщений в Telegram.

Workflow реализован в n8n с использованием DeepSeek, OpenAI, Telegram, Google Drive, Яндекс Диска и Tavily.
